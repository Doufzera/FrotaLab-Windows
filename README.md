# FrotaLab Windows

Aplicativo desktop de auditoria e preparacao de pacotes de veiculos FiveM/QBCore.

Esta versao oferece download dos 4 repositorios, importacao de ZIP local, verificacao de integridade, inventario, comparacao por hashes, relatorios e exportacao de arquivos ZIP organizados para instalacao. Nao altera geometria interna YFT/YTD nem garante melhora de FPS sem testes no jogo.

O executavel Windows e compilado pela rotina GitHub Actions em `.github/workflows/build-windows.yml`.
